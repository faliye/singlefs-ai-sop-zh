# 规则文件铁律

**管的是**：`rules/*.md`、项目本地的 `.claude/rules/*.md`，也就是**照着执行的规矩**。

设计文档照 `design-doc-discipline.md` 写，给模型检索的知识照 `kb-discipline.md` 写。
agent 定义与 skill 正文同规矩，检查各自另立。

## 1. 正文只写四样

| 写 | 不写 |
|---|---|
| 怎么做：步骤、次序、判据、阈值 | 为什么这么定：论证、取舍、推导 |
| 做什么、不做什么：射程与例外 | 这条怎么来的：实测、日期、谁定的、踩过的坑 |
| 推荐怎么做：拿不准时的默认选项 | 当时是什么样：旧值、旧做法、改动经过 |
| 什么规则在哪里：指到别的规则、脚本或 kb | 门禁判别力的经过与数 |

规则会被整篇读进每一轮工作的上下文。论证与经过挤在里面，执行的人和模型要先分辨
哪一句是命令、哪一句是背景，分辨错了就照着背景办事。

## 2. 判据留下，论证搬走

这两样最容易混，分界只有一句：

| | 长什么样 | 处置 |
|---|---|---|
| **判据** | 照它能判出该不该做、做到哪算完 | **留在正文** |
| **论证** | 解释那条判据为什么成立 | **删掉** |

- 「删掉这句，读的人少知道什么？说不上来就删」——判据，留下。
- 「啰嗦的代价不是占地方，是让有用的话被埋掉」——论证，删掉。

同一段里两样都有时，把判据那一句留在正文，其余整段删掉，不留摘要。

## 3. 搬出来的东西直接删掉

**不另立落点，也不去别处补一份。** 共享规则的历史照旧进 `CHANGELOG.md`，一版一节——那是唯一的落点。
删掉的论证以后要用，重新论证一次。

**搬完正文一个字都不留**：不写「（原为 X）」「此前如何」这类痕迹。

## 4. 指向历史的链接要带劝阻句

正文要指 `CHANGELOG.md`、`records/` 或 kb 里那份材料时，**同一行**写上劝阻句：

> 历史与依据：`CHANGELOG.md` 的 0.0.53 那一节。**除非要查来历，别读它。**

劝阻句写成「别读」或「不要读」，一字不许省。没有劝阻句的链接不许指过去——
读的人和模型默认跟着链接走，跟过去就把刚分出去的东西又装回了上下文。

## 5. 规则文件不留历史节

`CLAUDE.md` 与 `rules/*.md` 连文末的「## 历史版本」都不留。
共享规则的历史进 `CHANGELOG.md`，一版一节。

## 6. 立一条新规则之前，先问它能不能变成会失败的检查

判据与写法在 `sop-first.md` 的「边界」一节，这里不重复。

## 7. 正文不许用位置指代，也不许自称

指文档里位置的说法一律不写：「上一节」「下面那张表」「前面提到」「上述」「如下：」「同上」「见下节」，
以及「本条」「本节」「本表」「本文档」这类自称。

把位置写成名字：小节写成它的标题，表写成它判的那件事，别处的事实链到它所在的文件。

射程是 `rules/*.md`、`CLAUDE.md`、`agents/*.md`、`skills/*/SKILL.md`。
位置指代的判据与 `kb/*.md` 同一套，逐词的射程以 `kb-discipline.md` 第 1 条为准。

自称只判指文档结构的那几个词：「本节」「本章节」「本表」「本文档」「本条」。
「这个实验」「这条决策」「本实验」这类领域对象词**不判**——规范文本讲的就是怎么处理一条决策、
一个实验，那里的「这个实验」指的是工作对象，不是文档位置。
时间指代（「本轮」「这一轮」）也不判：规则对每一轮都生效，那里的「本轮」是泛指。
这两样在 `kb/*.md` 里照判。

规则文件带 `<!-- doc-lint:rule-definition -->` 牌时，反引号与「」里的举例不判，正文照判。

由 `scripts/doc-lint.sh` 强制。

## 8. 正文不写某一个使用者的东西

规范是给任何使用者读的。正文里不许出现使用它的项目的名字、它的路径、它的文件名，
也不许拿它的决策号、实验号当示例。举例写成不指名的形态：`.claude/gate.d/` 这类接法路径是共享约定，
写得；`.claude/gate.d/55-xxx.sh` 这种具体文件名写不得。

使用者名单登记在 `I18N` 的 `consumers=`，一处登记，别处不抄。
`scripts/rules-lint.sh` 判名字那一半；编号与文件名当示例这一半机器分不出，靠 review。

## 门禁管哪一半

`scripts/rules-lint.sh` 判第 1、3、4、5 条能落成字面的那一半——
记录小节、带日期的行、解释性段落与半句、词法说明、没带劝阻句的历史链接。
它扫本包的 `rules/`；项目把自己的规则目录用 `RULES_LINT_DIR` 交给它，在 `.claude/gate.d/` 里接一个本地阶段。
还没回扫完的文件逐个登记进项目根的 `.claude/rules-lint-exclude`，改完一个删一行，排除只缩不涨。

第 7 条由 `scripts/doc-lint.sh` 判，不由 `rules-lint` 判；第 8 条的名字那一半由 `rules-lint` 判。

**它管不了的**：第 2 条那条分界（哪一句是判据、哪一句是论证）、劝阻句底下的链接指得对不对。这几样是语义判断，靠人念一遍和 review。

⚠️ 它的判据是中文词表。别的语言仓里这一项显式报**未实现**，不假装通过（`show-me-test.md`：门禁不许假装通过）。
