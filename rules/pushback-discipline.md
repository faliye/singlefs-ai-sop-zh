# 警告记录

**管的是**：对一个提议提过异议、对方重申之后留下的记录。

## 警告写在哪：`.claude/warnings/<日期>.md`

**每个项目的 `.claude/warnings/` 下按日期建文件**，一天一个 `YYYY-MM-DD.md`，
一次警告一个 `##` 小节，四项都要有：

```markdown
# 2026-09-06

## 索引改成单棵树，不再留第二份

**提议**：<对方要做什么>
**异议**：<对不上的是哪一条：哪个实验、哪个数、哪条决策，带出处>
**已知风险**：<会出什么问题，什么现象说明它出现了>
**结果**：<对方重申了，照做 / 改了方案 / 撤回了>
```

**别处一律链过来，不抄第二份**（`kb-discipline.md` 第 4 条「矛盾比空白更糟」）。`kb/decisions.md` 里那条决策写一句「有警告，见
`.claude/warnings/2026-09-06.md`」就够，正文不复制。

写下的警告不再改，后来的事写进后来那天的文件。
记录写成中立的事实，不写「我早说过」。

## 门禁管哪一半

`scripts/doc-lint.sh` 查 `.claude/warnings/` 下的文件名
是不是 `YYYY-MM-DD.md`、每个 `##` 小节四项齐不齐。

它查不出「一个字都没记」。
