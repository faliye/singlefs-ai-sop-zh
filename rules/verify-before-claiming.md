# 陈述外部状态之前，现查一次

**凡是说「外面现在是什么样」的话，出口之前当场跑一条命令确认。**
记忆、kb、上一轮对话、TODO 表，都只是线索，不是证据。

「外面」指的是：不在这次对话里、而且可能在我不知道的时候被改过的一切。

| 要说的话 | 现查的命令 |
|---|---|
| 门禁现在过不过 | 跑 `scripts/gate.sh`，不要从上一轮结果推断 |
| 某个不变量实现了没 | 读 `kb/invariants.md` 的状态列，再 grep checker 源码确认它真的在 |
| 某个决策定了没 | 读 `kb/decisions.md`，看状态是「已定 / 半定 / 待定」哪一个 |
| 工具链 / 环境齐不齐 | 跑 `scripts/env.sh` |
| 别家文件系统怎么做的 | 现查它的文档或源码，并在 kb 里标上来源和「未在本项目验证」 |
| 测试镜像现在什么状态 | 现场跑 checker，不要靠「上次跑过是好的」 |

**不用现查的**：这次对话里刚读过的文件、纯代码逻辑推导、算术。

## 「它定了没」和「它到底怎么定义的」是两个问题

查了状态列、确认某条决策是「已定」，**不等于你知道它定的是什么**。
要拿一条决策去建模、写检查、或者推翻别的结论时，**得把它的定义逐字读一遍**，
不能照自己的印象建模。

实测：某个实验要测一条决策在新场景下会不会出错。建模时按自己的理解造了两种可能的语义，
测出「两种都会出错」，据此把那条决策推翻了。
而**那条决策的正文里早就写着第三种定义**——按它跑，错误恒等于零，
整个结论方向都是反的。事后回看：状态列查了，定义没读。

**做法**：拿一条决策去做任何推导之前，先把它的定义句原样贴进你的笔记或实验注释。
贴不出来，说明你在凭印象干活。

## 核了窄的那一句，说出口的却是宽的那一句

这一条最难自己发现，因为**「现查」那一步真的做了**：你跑了命令、读了文件，
手上确实有一条被核实的命题。**错在说出口的那句比它宽。**

**实测两处（2026-09-10，同一天同一个人）**：

| 核到的（窄，真的） | 说出口的（宽，假的） | 代价 |
|---|---|---|
| 「`sudo` 被沙箱拦下」 | 「拿不到 root，这个观测做不了」 | 同一个仓里另一条路**不需要那个权限**，而且文档里逐字写着「已实测通过」⇒ **整轮零观测，而记下来的理由是假的** |
| 「某条类规则的枚举里没列这个对象」 | 「这一格全仓没有落点」 | **类归属写在另外两个文件里**，那条类规则本来就罩着它 ⇒ 据此立的整个实验立题作废，同一笔欠账**连写错两次** |

两处形状相同：**被核实的是一条路 / 一个文件，被断言的是全部路 / 全仓。**

⇒ **判据：说出口的那句话，它的主语和范围，是不是就是你刚才核的那一个？**

- 核的是「这条路不通」⇒ 只能说「这条路不通」，**不能说「做不到」**。
- 核的是「这个文件里没写」⇒ 只能说「这个文件里没写」，**不能说「全仓没有」**。

⇒ **做法**：把要说的那句宽的话当成待证命题，问一句
「**要让它为真，需要排除掉哪些情况**」，然后逐个去排除。
排不完就把话缩回你真排完的那个范围——**缩过的话仍然有用，宽而假的话会让整轮工作建在它上面。**

⚠️ 「一个对象有没有被条款罩着」尤其容易中招：**条款可以写在别处，按类罩着它**，
而它自己那一节里一个字都没有。⇒ 判它之前，**拿它的名字全仓搜一遍**，
看它有没有被归进某个已有的类——**类规则会替它回答问题。**

## 落实

- **要改 kb 或 TODO 里任何一行状态，先跑那一行对应的命令。**
  不查就别重写它：留着旧的至少还带着日期，改一遍等于给错的东西盖了个新时间戳。
- 说不出「我是靠哪条命令知道的」，那句话就写成**推测**，不能写成事实。
- 别人提出的事实性更正**同样要核**。不照单全收，也不急着反驳，核完把结果说清楚。
