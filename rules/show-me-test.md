# 准入铁律：Show me test

> **Make every submitted patch review-worthy.**
>
> 让每一份提交都值得被 review。

## 判据是测试

**patch 收不收，由自动化验证说了算。** 门禁过就是过，不过就是不过。

## 没有测试的 patch 一律不收

**改了 `crates/*/src/` 或 `crates/*/build.rs` 就得带测试。** 没有例外，「这个太简单了」「下个 patch 补上」都不算。只改文档和脚本、或者只改了 `.rs` 里的注释的除外（去掉注释与空白之后代码与改前逐个相同才算只改注释；文档注释里会编成 doctest 的代码块、文档注释与 `// SAFETY:` 注释的增删照代码算；判法在 `scripts/comment-only-change.py`）。

由 `scripts/show-me-test.sh` 强制（`gate.sh` 把它当一个阶段跑）。

## 最终判据由项目定

单元测试这类检查只是快速反馈，**不是准入标准**。
准入标准跟被测对象绑在一起：要起什么环境、跑什么负载、注入什么故障，都由项目自己定、自己测、自己验，
装置和它的门禁阶段都放在项目里，共享门禁不带。
未实现清单里一直列着「最终判据」。写这个键之前，先把准入标准写进项目自己的 kb：起什么环境、跑什么负载、注入什么故障。
阶段把这几样都做到了，才在头部写 `# gate-covers: 最终判据`；只做到一部分的不写。
阶段覆盖了清单里别的哪一项，也一样写 `# gate-covers: <那一项>`。这一轮跑了且通过，`gate.sh` 才把那一项从未实现清单里换成「由哪个阶段覆盖」。

## 门禁不许假装通过

没实现的门禁阶段要**明说没实现**，不许悄悄跳过。

**项目本地阶段这一轮无对象可判，退出码写 77**：`gate.sh` 记「本次未跑」，不记通过，也不算覆盖。
`exit 0` 的跳过在汇总里与「判过了」分不出来，这一半靠写阶段的人。
共享阶段同规矩：无对象可判的退 77（`Show me test` 与命名纪律退 3），`gate.sh` 用认得 77 的起法起它们。

**阶段只跑了一部分，跳过的那一部分逐项报进汇总**：缺工具跳过的用例、本语言没实现的样本、没配样本的本地阶段，
用 `lib.sh` 的 `report_not_run` 报（不 source `lib.sh` 的阶段往 `$GATE_NOT_RUN_FILE` 追加一行，这个变量不在时不写：单跑与喂样本时它不在），
`gate.sh` 收进汇总的「本次未跑」；只在阶段输出里 warn 一句不算报了。报过的那一次不记成「上次成功」（`rules/preflight-discipline.md`），
报过的本地阶段也不算覆盖了 `# gate-covers:` 那一项。

**没记、跳过、作废的条目逐条进日志**：成功句或汇总报了「没记 N」「跳过 N」「作废 N」这类数的，同一份输出里逐条打出那些条目（条目多的打前 N 条，余下报条数）；只写进收尾会删的临时文件不算打出。

**扫到 0 项也不是通过。**
扫一批对象的检查，成功那句里要报出**检查了多少项**；`gate-lint.sh` 判这一条：判的是脚本里最后一句成功句，
它要带一个在脚本里数出来的量（累加过的变量、数组长度、`wc -l` / `grep -c` 的结果）；确实不扫对象的脚本单独写一行注释
`# gate-lint:nocount <理由>`，理由至少 8 个字。

**报了「查了多少」还不够，「没查的是哪些」也要逐个列出，而且清单要现算。**
**跳过清单要与被扫集合出自同一份数据、现算**；成功那句同时报「跑了 <个数> 个；没跑 <个数> 个：逐个列名」。
`gate-lint.sh` 判一半（只判 `.sh`）：输出里报了「跳过 N」「没记 N」「作废 N」「没跑 N」「未跑 N」这类数的脚本，同一份脚本里要有一行逐条打出条目的输出，写进文件的那一行不算；
条目在别处逐条打出、它认不出的，在报数那一行行尾写 `# gate-lint:skip-listed <理由>`，理由至少 8 个字。
清单是不是与被扫集合出自同一份数据、是不是现算，逐条打的是不是报数的那几样，它不判，靠写阶段的人自己守。

**项目本地阶段与共享阶段同规矩**，一样受 `gate-lint` 与 `shell-lint` 管：`gate.sh` 把项目登记的门禁目录（默认 `.claude/gate.d/`）一并交给这两个 lint。

**射程只到项目登记的门禁目录。** 项目别处的脚本（研究脚本、hook）不在这两个 lint 的射程里。
项目有这类目录，就在登记的门禁目录里接一个本地阶段，把它们交给这两个 lint，两个都要接：
调用时分别设 `GATE_LINT_DIR`、`SHELL_LINT_DIR` 指到目标目录。

## 分段计时在被测进程里计，不在转发输出的循环里计

包装程序起一个子进程、读它的输出行、逐行转打出去时，**不许拿每行读到的时刻当分段挂钟**。

**做法**：在被测进程里自己计时，把数写进结果行；非要按到达时刻切，先把子进程的输出整份读完再转打。
外层与里层两个数都有时，报一个包含自检：外层那一段必须包住里层那一段，包不住的轮不进统计。

门禁阶段「转发计时」（`scripts/relay-timing-lint.py`）判：项目里 `.rs` 与 `.py` 中读子进程输出的循环（扫哪些目录以那个脚本为准）不许一边给行打时间戳、一边把行转打出去。

## 每一个弄坏开关都必须会红

弄坏开关指只给自证用、打开后故意弄坏一处的开关。

- 每一条开关都逐个打开跑一遍自证：自证必须退非 0，并且红在开关表里点名的那一格。
- 打开后不红、或红的不是点名那一格的开关，当场修：改自证让它红在那一格，或改开关让它真的弄坏点名的那一处；两样都修不了就删掉这条开关。不留不会红的开关。
- 加了开关、改了开关表、改了开关弄坏的那段代码，受影响的开关逐条重跑。

python 写的门禁与钩子在 `--selftest` 的收尾照 `scripts/break-switch-selftest.py` 逐个打开开关核；shell 写的在 `scripts/selftest.sh` 里每个开关写一条必红的用例。
